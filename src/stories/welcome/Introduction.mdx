## Components

| Component | Description |
|-----------|-------------|
| **Avatar** | User photo, initials, or placeholder in multiple sizes and shapes |
| **AvatarGroup** | Stacked collection of Avatars with overflow count |
| **Button** | Primary, secondary, and ghost actions with size and state variants |
| **Card** | Content container with title, description, tag, and image slots |
| **Checkbox** | Selection control with selected, indeterminate, and disabled states |
| **Chip** | Compact label for statuses and categories |
| **Dialog** | Modal overlay for confirmations and focused tasks |
| **DropArea** | Drag-and-drop file upload zone |
| **FilterChip** | Toggleable filter pill with optional close action |
| **Icon** | FontAwesome icon wrapper with size and style variants |
| **Input** | Text field with label, helper, error states, and icons |
| **List** | Vertical list with interactive or static items |
| **MenuGroup** | Grouped section of menu items with optional heading |
| **MenuItem** | Single row in a navigation or action menu |
| **RadioButton** | Exclusive selection control within a group |
| **Sidenav** | Collapsible sidebar navigation with nested items |
| **Switch** | Boolean toggle with on/off states |
| **Table** | Data grid with sorting, pagination, and row selection |
| **Tabs** | Horizontal or vertical tab bar with active indicator |
| **Tooltip** | Contextual hint on hover with configurable placement |
| **TopBar** | Application header bar with title, actions, and branding |
| **Widget** | Dashboard card with header, body, and optional actions |

## Getting started

### Install dependencies

```bash
npm install
```

### Run Storybook locally

```bash
npm run storybook
```

This builds design tokens from Figma exports then starts Storybook at `http://localhost:6006`.

### Use a component

```tsx
import { Button, Input, Avatar } from 'thelocker-storybook';

function Example() {
  return (
    <div>
      <Avatar size="medium" type="initials" fallback="DP" />
      <Input label="Email" placeholder="you@example.com" />
      <Button variant="primary" size="medium">Submit</Button>
    </div>
  );
}
```

### Use a token

```css
.my-card {
  background: var(--color-background-default);
  border: 1px solid var(--color-stroke-neutral-strong);
  border-radius: var(--radius-medium);
  padding: var(--space-4);
}
```

## Figma ↔ Code

This Storybook is connected to the Figma source file via **Code Connect**. Designers see the matching code snippet directly in Figma Dev Mode when they inspect a component.

To re-publish after updating templates:

```bash
FIGMA_ACCESS_TOKEN=<token> npx figma connect publish
```
