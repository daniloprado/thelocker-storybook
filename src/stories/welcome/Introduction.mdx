## Getting started

### Install dependencies

```bash
npm install
```

### Run Storybook locally

```bash
npm run storybook
```

This builds design tokens from Figma exports then starts Storybook at `http://localhost:6006`.

### Use a component

```tsx
import { Button, Input, Avatar } from 'thelocker-storybook';

function Example() {
  return (
    <div>
      <Avatar size="medium" type="initials" fallback="DP" />
      <Input label="Email" placeholder="you@example.com" />
      <Button variant="primary" size="medium">Submit</Button>
    </div>
  );
}
```

### Use a token

```css
.my-card {
  background: var(--color-background-default);
  border: 1px solid var(--color-stroke-neutral-strong);
  border-radius: var(--radius-medium);
  padding: var(--space-4);
}
```

## Figma ↔ Code

This Storybook is connected to the Figma source file via **Code Connect**. Designers see the matching code snippet directly in Figma Dev Mode when they inspect a component.

To re-publish after updating templates:

```bash
FIGMA_ACCESS_TOKEN=<token> npx figma connect publish
```
