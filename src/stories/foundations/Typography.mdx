# Typography

The Locker 2.0 uses **Mulish** as the single font family for both headings and body text. Type tokens define size, weight, and line height at each level of the hierarchy.

---

## Font families

| Role | Family | CSS variable |
|------|--------|-------------|
| Heading | Mulish | `--font-family-heading` |
| Body | Mulish | `--font-family-body` |

---

## Line heights

| Token | Value | CSS variable |
|-------|-------|-------------|
| 16 | 16px | `--font-line-height-16` |
| 20 | 20px | `--font-line-height-20` |
| 24 | 24px | `--font-line-height-24` |
| 28 | 28px | `--font-line-height-28` |
| 32 | 32px | `--font-line-height-32` |
| 40 | 40px | `--font-line-height-40` |
| 48 | 48px | `--font-line-height-48` |
| 56 | 56px | `--font-line-height-56` |

---

## Usage

```css
.page-title {
  font-family: var(--font-family-heading);
  font-size: var(--font-size-heading-1);
  font-weight: var(--font-weight-bold);
  line-height: var(--font-line-height-48);
}

.body-text {
  font-family: var(--font-family-body);
  font-size: var(--font-size-body);
  font-weight: var(--font-weight-regular);
  line-height: var(--font-line-height-24);
}
```
