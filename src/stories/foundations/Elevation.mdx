# Elevation

Elevation separates surfaces from each other using subtle shadows, giving the interface a sense of depth and hierarchy.

---

## Levels

The Locker 2.0 currently relies on **border-based** elevation rather than shadow tokens. Components sit on distinct surface layers through background color and stroke differences.

## Approach

Instead of explicit `box-shadow` tokens, surfaces are distinguished by:

1. **Background color** — `--color-background-default` vs `--color-background-emphasis`
2. **Border strokes** — `--color-stroke-neutral-strong` for subtle, `--color-stroke-primary-strong` for focused/active
3. **Border radius** — Larger radius (`--radius-large`) for overlay surfaces

If dedicated shadow tokens are added to the Figma variables in the future, they will be automatically synced here.

---

## Usage

```css
.card {
  background: var(--color-background-default);
  border: 1px solid var(--color-stroke-neutral-strong);
  border-radius: var(--radius-medium);
}

.dialog-overlay {
  background: var(--color-background-default);
  border: 1px solid var(--color-stroke-neutral-weak);
  border-radius: var(--radius-large);
}
```
