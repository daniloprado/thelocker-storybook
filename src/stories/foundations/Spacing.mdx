# Spacing

A consistent spacing scale creates visual rhythm across components and layouts. All values are multiples of 4px.

---

## Component heights

Fixed height tokens used for interactive elements (buttons, inputs, chips).

<div style={{ display: 'grid', gap: 12, marginTop: 16 }}>
  {[
    { name: 'Height/Small', var: '--space-height-small', value: 24 },
    { name: 'Height/Medium', var: '--space-height-medium', value: 32 },
    { name: 'Height/Large', var: '--space-height-large', value: 40 },
  ].map((item) => (
    <div key={item.var} style={{ display: 'flex', alignItems: 'center', gap: 16 }}>
      <code style={{ width: 180, fontSize: 12, flexShrink: 0 }}>{item.var}</code>
      <div style={{ width: 120, height: item.value, background: 'var(--color-background-emphasis, #F8F8F8)', border: '1px solid var(--color-stroke-neutral-strong, #DBDBDB)', borderRadius: 6, display: 'flex', alignItems: 'center', justifyContent: 'center', fontSize: 11, color: '#666', flexShrink: 0 }}>
        {item.value}px
      </div>
    </div>
  ))}
</div>

---

## Usage

```css
.card {
  padding: var(--space-4);         /* 16px */
  gap: var(--space-3);             /* 12px */
}

.button--medium {
  height: var(--space-height-medium); /* 32px */
  padding: 0 var(--space-4);         /* 0 16px */
}

.stack > * + * {
  margin-top: var(--space-2);      /* 8px */
}
```
