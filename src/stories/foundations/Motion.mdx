# Motion

Motion guidelines for transitions and animations across The Locker 2.0 interface.

---

## Principles

1. **Purposeful** — Animation guides attention, never distracts
2. **Fast** — Micro-interactions complete in under 200ms
3. **Consistent** — The same easing and duration patterns are reused everywhere

---

## Recommended durations

No explicit motion tokens exist in the Figma variables yet. The following conventions are used across components:

## Easing

| Curve | Value | Use |
|-------|-------|-----|
| Ease out | `cubic-bezier(0.25, 0, 0.25, 1)` | Elements entering the screen |
| Ease in-out | `cubic-bezier(0.42, 0, 0.58, 1)` | Elements that move or resize |
| Linear | `linear` | Progress indicators, loading bars |

---

## Examples in code

```css
.tooltip {
  opacity: 0;
  transition: opacity 200ms cubic-bezier(0.25, 0, 0.25, 1);
}
.tooltip--visible {
  opacity: 1;
}

.sidebar {
  width: 64px;
  transition: width 300ms cubic-bezier(0.42, 0, 0.58, 1);
}
.sidebar--expanded {
  width: 240px;
}
```
