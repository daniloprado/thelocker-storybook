# Changelog

Summarised updates to The Locker 2.0 design system, newest first.

---

### September 28, 2026

**<DocLink id="components-buttons">Button</DocLink> synced to latest Figma (135 variants)**

- Props now mirror the Figma set: `variant` = **Style** (`primary`, `secondary`, `neutral`, `destructive`), `appearance` = **Type** (`filled`, `outline`, `text`, `ghost`), plus `size` and `state`.
- New `leadingIcon` / `trailingIcon` booleans (Figma Leading / Trailing Icon) with `leadingIconCode` / `trailingIconCode` and `leading` / `trailing` slots. Icons use the <DocLink id="components-icon">Icon</DocLink> component (16px Large/Medium, 12px Small).
- Defaults match Figma: Secondary, Filled, Large. `action` prop removed; use `variant="destructive"`.
- Filled types use Bold; Outline, Ghost and Text use Regular. Text type has no padding and hugs the label.
- Focus is a 3px inside ring per style (Yellow/400, Blue/200, Red/400, Red/200, Grey/400). Outline hover/active use Stroke/Neutral/Stronger → Strongest.
- Added `Stroke/Neutral/Strongest` (`--color-stroke-neutral-strongest`, Neutral/500) to the token export.

**<DocLink id="components-tabs">Tabs</DocLink> synced to latest Figma**

- New `large` size for pill tabs (<DocLink id="components-chip">Chip</DocLink> Large, 32px). Pill maps small → <DocLink id="components-chip">Chip</DocLink> Small, default → <DocLink id="components-chip">Chip</DocLink> Medium, large → <DocLink id="components-chip">Chip</DocLink> Large.
- Standard tabs are Bold in both states (Text/Weak → Text/Strong when active). Active indicator is the Figma 2px `Stroke/Neutral/Strong` inside stroke; the group no longer draws its own baseline.
- Code Connect added for <DocLink id="components-tabs">Tab Group</DocLink> and <DocLink id="components-tabs">Tab Item</DocLink>.

**New: <DocLink id="components-icon-fancy-icon">Fancy Icon</DocLink>** (`Components/Icon/Fancy Icon`)

- Tinted container around <DocLink id="components-icon">Icon</DocLink>. `size` small / medium / large (24 / 32 / 40px; Figma "Meidum" maps to `medium`), `color` blue (Decorative/Blue) or neutral (Grey/200 + Grey/600).
- Nested <DocLink id="components-icon">Icon</DocLink> sizes follow Figma: xsmall / small / medium.

**New: <DocLink id="components-empty-state">Empty State</DocLink>**

- <DocLink id="components-icon-fancy-icon">Fancy Icon</DocLink> (Large, Neutral) + heading (Bold 16, Text/Weak) + description (Regular 14/20) + Primary Text <DocLink id="components-buttons">Button</DocLink> with leading `plus` icon.
- Booleans mirror Figma: `showIcon`, `showHeading`, `showDescription`, `showButton` (Figma "Shot button"). `icon` and `action` slots override the defaults.

**<DocLink id="components-card">Card</DocLink>**

- Media placeholder fill set to Figma's `#FAFAFA`.

**<DocLink id="components-input">Input</DocLink> placeholder**

- Placeholder color now uses `Input/Text/Placeholder` (`#B6B6B6`). It was falling back to Neutral/400 (`#6D6A6A`), which read as filled text.

---

### September 17, 2026

**<DocLink id="components-card">Card</DocLink> synced to latest Figma**

- New `type`: **Empty**, **Vertical** (default), **Horizontal**. Horizontal places the media slot on the left.
- <DocLink id="components-card">Card</DocLink> padding is Spacing/3 (12px). Media sits inset with Radius/Medium, not flush to the border.
- Vertical body padding is Spacing/5 × Spacing/4. Empty and Horizontal keep Spacing/5 × Spacing/6.
- `image={false}` still hides the top slot. Tag remains <DocLink id="components-chip">Chip</DocLink> Yellow Small.

---

### August 18, 2026

**<DocLink id="components-card">Card</DocLink> synced to latest Figma**

- Tag uses <DocLink id="components-chip">Chip</DocLink> **Yellow** (was Blue). Title and description use Bold/Regular Body (16/24).
- New `image` boolean (Figma **Image**) hides the top slot. `topSlot` maps to the Figma Top Slot; Body remains `children`.
- Description clamps to two lines with ellipsis. Body padding is Spacing/5 × Spacing/6. Border uses Stroke/Neutral/Strong; fill uses Background/Default.

**Color tokens resynced from Figma**

- Export now follows Figma collections: **Primitives**, **Colors**, **Design**, **Typography**.
- Added `Text/Link`, `Icon/Primary`, `Input/Stroke/Warning`, `Stroke/Neutral/Stronger`, and the 10 **Decorative** tokens.
- Fixed `Icon/Warning` to Red/600 (`#D44D5C`). Duplicate primitive aliases (e.g. Grey/Lightest) are no longer exported.
- Updated `Grey/600` (`--color-grey-600`) from `#B9B9B9` to `#B6B6B6`. Aliased semantics updated: `Stroke/Neutral/Stronger`, `Input/Text/Placeholder`, `Input/Text/Disabled`.

### August 14, 2026

**<DocLink id="components-chip">Chip</DocLink> synced to latest Figma**

- New `whiteStrong` color: white fill with Neutral/500 (`#241F20`) border, distinct from `white` (Grey/500 border).
- Leading and trailing slots (`leading` / `trailing`). Figma booleans map to `showLeadingIcon` / `showTrailingIcon` and now default **off**.
- Code Connect maps **White Strong** → `whiteStrong` and the slot booleans.

**<DocLink id="components-tabs">Tabs</DocLink> pill style composes <DocLink id="components-chip">Chip</DocLink>**

- Pill tabs render <DocLink id="components-chip">Chip</DocLink>: active uses `whiteStrong`, inactive uses `neutral`.
- Default size uses <DocLink id="components-chip">Chip</DocLink> Medium; Small uses <DocLink id="components-chip">Chip</DocLink> Small. Group gap is `--space-1` (4px).
- Standard tabs follow Figma padding and type. <DocLink id="components-tabs">Tabs.Item</DocLink> accepts optional `trailing` (e.g. calendar icon on default Standard).

**Storybook docs**

- New <DocLink id="welcome-introduction">Welcome/Introduction</DocLink> page with overview, catalog, and getting started.
- New <DocLink id="foundations-radius">Foundations/Radius</DocLink> page. <DocLink id="foundations-typography">Typography</DocLink>, <DocLink id="foundations-spacing">Spacing</DocLink>, <DocLink id="foundations-elevation">Elevation</DocLink>, and <DocLink id="foundations-motion">Motion</DocLink> pages expanded to show the full token scales.

**Experiment: <DocLink id="experiment-dashboard" story="default">Dashboard</DocLink>**

- Added a composed <DocLink id="experiment-dashboard" story="default">Dashboard</DocLink> story using <DocLink id="templates-app-shell" story="default">App Shell</DocLink>, <DocLink id="components-table">Table</DocLink>, <DocLink id="components-tabs">Tabs</DocLink>, <DocLink id="components-chip">Chip</DocLink>, and other library components.

**Figma Code Connect**

- Published Code Connect templates for library components, including <DocLink id="components-avatar">Avatar</DocLink>.
