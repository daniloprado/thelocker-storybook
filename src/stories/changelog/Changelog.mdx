# Changelog

Summarised updates to The Locker 2.0 design system, newest first.

---

### August 14, 2026

**Chip synced to latest Figma**

- New `whiteStrong` color: white fill with Neutral/500 (`#241F20`) border, distinct from `white` (Grey/500 border).
- Leading and trailing slots (`leading` / `trailing`). Figma booleans map to `showLeadingIcon` / `showTrailingIcon` and now default **off**.
- Code Connect maps **White Strong** → `whiteStrong` and the slot booleans.

**Tabs pill style composes Chip**

- Pill tabs render `Chip`: active uses `whiteStrong`, inactive uses `neutral`.
- Default size uses Chip Medium; Small uses Chip Small. Group gap is `--space-1` (4px).
- Standard tabs follow Figma padding and type. `Tabs.Item` accepts optional `trailing` (e.g. calendar icon on default Standard).

**Storybook docs**

- New **Welcome/Introduction** page with overview, catalog, and getting started.
- New **Foundations/Radius** page. Typography, Spacing, Elevation, and Motion pages expanded to show the full token scales.

**Experiment: Dashboard**

- Added a composed Dashboard story using App Shell, Table, Tabs, Chip, and other library components.

**Figma Code Connect**

- Published Code Connect templates for library components, including Avatar.

---

### August 13, 2026

**7 new components added from Figma**

- **Card** — Content card with 4 size variants (small, medium, large, stretch), image slot, tag, title, and description.
- **Tabs** — Compound component (`Tabs` + `Tabs.Item`) with horizontal/vertical orientations and default/small sizes.
- **Checkbox** — Selection control with unselected, selected, indeterminate, and disabled states.
- **RadioButton** — Selection control with unselected, selected, and disabled states.
- **Switch** — Toggle control (42x24) with unselected, selected, and disabled states.
- **List** — Compound component (`List` + `List.Item`) with simple text rows and avatar-based user rows.
- **Tooltip** — CSS-only hover tooltip with top/bottom/left/right positions.
- **Widget** — Dashboard card container with header, action slot, and content body.
- **FilterChip** — Filter tag with default, selected (yellow), disabled states and optional close button.

**14 missing design tokens added**

- Added 10 decorative color tokens: `--color-decorative-{blue,yellow,green,orange,pink}-{strong,weak}`.
- Added semantic tokens: `--color-text-link`, `--color-icon-primary`, `--color-input-stroke-warning`.
- Fixed bug: `--color-icon-warning` was incorrectly mapped to green (#45C987) instead of red (#D44D5C).

---

### July 23, 2026

**New component: Dialog**

- Created `Dialog` component with two variants: `scroll` (full-width, scrollable body) and `simple` (compact).
- Props: `title`, `variant`, `open`, `showOverlay`, `onClose`, `footer`, `headingLeft`, `headingRight`, `width`.
- Reuses existing `Button` and `Icon` components for footer actions and close button.
- Added stories: Playground, Scroll, Simple, With Overlay, Heading Slots, Destructive Action.
- Exported from `index.ts` and registered in `sourceDocs`.

**Input component synced to Figma**

- Created `Input/Stroke/Warning` variable in Figma (aliased to `Yellow/500`).
- Fixed scopes on all 11 `Input/*` variables (from `ALL_SCOPES` to proper `TEXT_FILL`, `FRAME_FILL`, `STROKE_COLOR`).
- Set WEB code syntax (`var(--color-input-*)`) on all Input variables for Dev Mode.
- Built Input ComponentSet in Figma with 27 variants (3 Sizes × 3 Statuses × 3 States), fully bound to design tokens.
